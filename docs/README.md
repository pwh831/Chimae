# docs

프로그램 개발의 기준이 되는 문서를 모아두는 곳입니다.

## 구조

| 경로 | 용도 |
| --- | --- |
| `docs/prd/` | PRD(제품 요구사항 문서). 무엇을 왜 만드는지. |
| `docs/prompts/` | 프롬프트 파일. AI에게 넘길 지시문·템플릿. |

## 규칙

- 파일은 마크다운(`.md`)으로 작성합니다.
- 이름은 소문자 + 하이픈을 씁니다. 예: `docs/prd/user-auth.md`
- PRD가 하나뿐이면 `docs/prd/main.md`로 시작해도 됩니다.
- 문서를 고치면 코드와 함께 커밋해서, 왜 바뀌었는지 이력이 남게 합니다.

## 사용법

작업을 요청할 때 경로로 짚어주면 됩니다.

> `docs/prd/main.md` 읽고 1단계부터 구현해줘
